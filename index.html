FAQ

QUESTIONS

Why does PiP fail on some sites? +

Two usual suspects: DRM-protected players (Netflix and friends) that block PiP, and sites sending Permissions-Policy: picture-in-picture=(). The diagnostics panel tells you which one.

Does it collect any data? +

No. No analytics, no telemetry, no remote server. The script runs only when you click, use the shortcut, or use the context menu.

Why can't it work on chrome:// pages? +

Chrome blocks extensions on its own pages, the Web Store, and some local files. No extension can bypass that.

Can I use it in Firefox? +

Not yet. The manifest and chrome.* API usage need a compatibility layer. Contributions welcome.
